# ADC / Sensor Status Summary - 2026-06-01

## 概要

Raspberry Pi + MCP3204/MCP3208 ADCで、水位センサ、照度センサ、DHT11温湿度センサの実機確認を行った。

詳細ログは `docs/ADC_DEBUG_SESSION_2026-06-01.md` に記録済み。

## 現在の結論

- SPIは有効化済みで、`/dev/spidev0.0` と `/dev/spidev0.1` がADCスクリプトから見えている。
- ADCは複数チャンネルで値を読めており、SPI/ADC全体は動作している。
- CH0の水位センサは、乾燥/拭き取り、浅水、深水、水膜で明確に値が変わる。
- CH1の照度センサは、明るい状態と指で覆った暗状態で明確に値が変わる。
- DHT11はリトライが多いが、温湿度取得には成功している。

## 配線メモ

### ADC

- MCP3204/MCP3208 `VDD` -> 3.3V
- MCP3204/MCP3208 `VREF` -> 3.3V
- MCP3204/MCP3208 `AGND` -> GND
- MCP3204/MCP3208 `DGND` -> GND
- MCP3204/MCP3208 `CH0` -> 水位センサ `Signal`
- MCP3204/MCP3208 `CH1` -> 照度センサ `AO`

### SPI

- GPIO11 / SCLK -> ADC `CLK`
- GPIO9 / MISO -> ADC `DOUT`
- GPIO10 / MOSI -> ADC `DIN`
- GPIO8 / CE0 -> ADC `CS/SHDN`

### DHT11

- DHT11 `VCC` -> 3.3V
- DHT11 `GND` -> GND
- DHT11 `DATA` -> GPIO4
- DHT11 `DATA` -> 10kohm -> 3.3V

## 水位センサ CH0

センサは3ピン、`VCC` / `GND` / `Signal` の平行銅線式 水位・雨滴センサーモジュール。

| 状態 | raw | 電圧 | 判断 |
|---|---:|---:|---|
| 拭き取り/乾燥 | 0 | 0.000V | 乾燥として扱える |
| 浅く少しだけ水につける | 1427-1872 | 1.150-1.509V | 中間状態として取れている |
| 深めに水没 | 2177-2201 | 1.754-1.774V | 水ありとして十分検出可能 |
| センサ面に水膜をまんべんなく塗る | 2371-2391 | 1.911-1.927V | 濡れ面積が大きいと深水より高く出る |

### 水位センサの判断

- 乾燥/拭き取り時は `raw=0` に戻る再現性がある。
- 水に触れると `raw=1400` 以上へ大きく上がる。
- 深水よりも、水膜がセンサ面全体に広がった状態の方が高く出た。
- このセンサは水位の深さだけでなく、濡れ面積と水膜のつながりに強く反応する。

### 暫定しきい値案

本番統合前に追加測定は必要だが、現時点では以下の判定が現実的。

| 判定 | raw目安 |
|---|---:|
| dry | `< 200` |
| wet / low water | `>= 800` |
| strong wet / enough water | `>= 1800` |

実装時は瞬間値ではなく、複数回平均とヒステリシスを入れる。

例:

- 5回読み取りの中央値を使う。
- `dry -> wet` は `raw >= 800` が連続2回。
- `wet -> dry` は `raw < 200` が連続2回。
- `enough water` は `raw >= 1800`。

## DHT11温湿度

`debug_dht11.py --retries 5 --interval 2` を権限付きで実行した。

結果:

- attempt 1-4: checksum / full buffer retry
- attempt 5: `temperature=29.9C`, `humidity=52.0%`

### DHT11の判断

- DHT11は取得に成功した。
- ただしリトライが多く、通信は不安定。
- DATAの10kohmプルアップ、配線接触、GPIO4、読み取り間隔を確認する。
- 本番処理ではリトライ前提で扱う必要がある。

## 注意点

- Raspberry Pi GPIOとMCP3204/MCP3208入力へ5Vを入れない。
- MCP3204/MCP3208の `VREF` が3.3Vの場合、ADC入力は3.3V以下にする。
- 5V駆動センサを試す場合は、必ず `Signal-GND` 電圧をテスターで測り、3.3V以下であることを確認してからADCへ接続する。
- `docs/config.js` はGitHub Pages公開対象なので、秘密情報を入れない。

## 次の実装方針

1. ADC読み取り処理を `send_sensor.py` へ統合する前に、ADC用の小さな読み取り関数を分離する。
2. CH0を `water_raw` / `water_voltage` / `water_status` として扱う。
3. CH1を `light_raw` / `light_voltage` / `light_status` として扱う。
4. raw値はノイズ対策として複数回読み、中央値または平均を使う。
5. ローカルAPI、SQLite、Supabaseへ保存する場合はDBスキーマ変更が必要なため、事前に移行方針を決める。
