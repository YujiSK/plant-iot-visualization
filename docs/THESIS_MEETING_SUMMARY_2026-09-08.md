# 卒業研究 進捗・打ち合わせ用サマリ

更新日: 2026-09-08

> 本資料は、現時点の進捗と今後の研究案を整理し、指導教員との打ち合わせで研究目的・評価方法・実験規模・スケジュールを相談するためのものです。今後の研究計画は、打ち合わせ内容を踏まえて確定します。

## 1. これまでの研究経緯と現在検討している方向

本研究では当初から、フェルト等を用いた毛細管現象による受動給水を植物管理システムへ取り入れてきた。初期には給水材の吸水・給水挙動について簡易的な測定も行ったが、その後はIoT監視システムの構築・連続運用に研究の比重が移った。

これまでに、Raspberry Piを中心として以下を構築・運用している。

- DS18B20による養液温度計測
- BH1750による照度計測
- フロートスイッチによる水位状態取得
- Vitality Scoreによる状態指標算出
- FastAPI等によるデータ処理
- Supabaseへのログ蓄積
- GitHub Pages等による可視化
- LINE / Slack等への通知機能

なお、**Vitality Scoreは本システム内で定義した補助的な状態指標であり、植物の生理的な「活力」を直接測定・検証した指標ではない**。そのため、植物状態の客観的な正解値や異常検知の正解ラベルとしては扱わず、センサ値から算出される参考指標として位置づける。

毛細管給水方式自体は実際の栽培でも継続使用していたが、給水性能について、比較条件・反復数・評価指標を揃えた定量評価は十分に実施できていない。

そこで現時点では、新たに研究テーマを変更するのではなく、**当初から扱ってきた毛細管現象による受動給水の定量評価を補完し、その上で既存のIoTセンシングをどのように位置づけるかを検討する**方向を候補として考えている。

研究質問は、現時点では以下の主・副構成を想定している。

**主たる研究質問（案）**

> 毛細管現象を利用した受動給水は、小規模な植物管理において、どのような条件でどの程度安定して給水できるか。

**副次的な研究質問（案）**

> 毛細管給水の状態や給水経路の異常を、既存のIoTセンシングによってどこまで把握できるか。

この主従関係が卒業研究として適切かは確定事項ではなく、今回の打ち合わせで相談したい。

## 2. 既存成果と現在確認できていること

### 連続運用データとIoT計測基盤の継続性

異常事象直前までの以下の区間を解析している。

- 2026-07-22 13:05 JST ～ 2026-08-02 19:15 JST
- 対象: raspberrypi2 / location-b
- 通常観測周期: 約5分

| 指標 | 結果 |
|---|---:|
| 期待観測枠 | 3,243 |
| 対応観測枠 | 3,240 |
| 欠測枠 | 3 |
| 取得率 | **99.91%** |
| 欠測率 | **0.09%** |
| 期待時刻からの平均ずれ | **0.600秒** |

この結果は、毛細管給水性能そのものではなく、**約11日間にわたりIoT計測・クラウド記録を高い継続性で実施できたことを示す結果**として位置づけている。つまり、取得率99.91%は「給水が99.91%正常だった」という意味ではないが、今後の状態解析に利用できる連続ログ基盤を構築・運用できたことを示す既存成果である。

また、この区間では養液温度が平均33.06℃、30℃以上の観測が87.8%を占めていた。植物への影響については、植物種や栽培条件に関する文献等と照合した上で評価する必要がある。

### 連続運用中に確認された異常事象

2026-08-04に家族が確認した際、栽培装置は転倒し、植物は著しく萎凋・枯死した状態で、電源コードも抜けていた。

保存ログでは、2026-08-02 19:15頃までは通常状態の観測があり、その直後の19:16:39に、水位の `water_ok` → `low_water`、`float_switch_triggered = true`、Vitality Score 約79 → 5、照度急変、DS18B20 85.0℃などの急激な変化が記録され、その後Supabaseへの観測は約39時間途絶している。

ここでのVitality Score 約79 → 5は、同時刻に生じたセンサ入力の急変に伴う算出値の変化として扱う。**この値の低下のみをもって植物の萎凋・枯死を検知した、あるいは植物の生理状態が79から5へ低下したとは解釈しない。**

このため、8月2日19:16頃に装置・センサ系へ何らかの急激な異常が発生した可能性は高いと考えている。ただし、8月4日は発見日であり、「19:16に転倒した」「特定の原因で転倒した」とは断定しない。

この事象は現時点では卒業研究の中心的評価対象とは決めておらず、連続運用時の補助的な異常事例としてどの程度扱うべきかを相談したい。

## 3. 現時点の主要な評価不足

現在の連続運用データから確認できるのは、主として貯水部の水位状態、養液温度、照度、Vitality Score（補助指標）、システムのデータ取得状況である。

一方、以下は十分に評価できていない。

- 毛細管現象による単位時間当たりの給水量
- 給水材による輸送性能と時間的安定性
- 条件差による給水性能の変化
- 貯水部から植物側まで実際に給水が成立しているか
- 給水経路の異常をIoTデータからどこまで把握できるか

特に、現在の計測系では、

> 貯水部に水が存在する
> → 毛細管材が水を輸送する
> → 根域へ水が到達する
> → 植物が必要量を利用できる

という各段階を区別して直接計測できていない。現在のIoTシステムが直接把握しているのは主として貯水状態と周辺環境であり、給水経路そのものには観測上のギャップがある。

このギャップを定量実験や補助計測によってどこまで埋めるべきか、また既存IoTセンシングとの対応をどこまで卒業研究で扱うべきかを相談したい。

## 4. 10月6日までの追加評価案

10月6日の研究室内発表までには、全ての本評価を完了させるのではなく、**研究質問と評価方法を固め、予備的に「実験 → 解析 → 考察」まで一度通す**ことを目標案として考えている。

### A. 毛細管給水の基礎特性評価

多数の要因を同時に変えず、まず1つの主要因だけを変化させ、それ以外を固定する構成を想定している。

例:

- 給水材は実機で使用しているフェルトに固定
- 材質・幅・厚さ・浸漬長・容器形状・初期水量などを可能な限り統一
- 独立変数は高さ差など1要因に限定し、少数条件（例: 3条件程度）で比較
- 給水量・給水速度・時間変化を測定
- 給水材なしの対照条件を設け、容器表面等からの蒸発量を見積もる
- 可能であれば、供給元の減少量だけでなく受け側への到達水量も測定
- 各条件で必要な反復を実施

給水材なしの対照条件は、容器表面等から生じる蒸発の影響を見積もるためのものであり、**この対照との差分だけで純粋な毛細管輸送量を完全に分離できるとは考えていない**。実際には濡れたフェルト自体からの蒸発も生じ得るため、毛細管輸送量をより直接的に評価するには、受け側へ実際に到達した水量を測定できる構成の方が望ましいと考えている。

高さ差は現時点の一例であり、最終的な独立変数・条件数・反復数・蒸発影響の扱いについては打ち合わせ後に決定したい。

### B. 実植物での短期運用・正常／異常の予備比較

基礎評価の結果を踏まえ、実植物を数日程度連続運用し、既存IoTログとの対応を見る案を考えている。

正常条件に加え、給水材の接触不良・給水経路の断絶など、安全に再現可能な少数の異常条件を比較する。必要に応じて、重量変化等の補助計測も併用し、既存IoTだけで給水成立を判断しないようにする。Vitality Scoreについても、客観的な植物状態の正解値としてではなく、他のセンサ値・補助計測と併せて参考指標として扱う。
