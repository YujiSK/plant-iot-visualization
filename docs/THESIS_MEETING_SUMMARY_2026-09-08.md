# 卒業研究 進捗・打ち合わせ用サマリ

更新日: 2026-09-08

## 1. 現在の研究方向

植物管理システムについて、単なるIoTシステムの構築・可視化で終えるのではなく、以下を組み合わせた研究として整理を進めている。

- 毛細管現象を利用した受動給水機構
- IoTセンシングによる環境・給水状態の継続観測
- 長期運用時の安定性評価
- 給水・装置異常時の状態変化および検知可能性の評価

現時点の研究上の問いは、概ね以下を想定している。

> 毛細管現象を利用した受動給水は、小規模な植物管理においてどの程度安定して機能するか。また、その給水状態や異常をIoTセンシングによってどこまで観測・検知できるか。

この研究目的・評価方法が卒業研究として妥当かについて、今回の打ち合わせで確認したい。

---

## 2. これまでに構築・実施した内容

### システム

Raspberry Piを中心として植物IoTシステムを構築し、実植物を用いた継続運用を行った。

主な構成・機能:

- DS18B20による養液温度計測
- BH1750による照度計測
- フロートスイッチによる水位状態取得
- Vitality Scoreによる状態指標算出
- FastAPI等によるデータ処理
- Supabaseへのセンサログ蓄積
- GitHub Pages等による可視化
- LINE / Slack等への通知機能

栽培時の給水には、フェルト等を利用した毛細管現象による受動給水方式を採用していた。

### 長期運用データ

事故前の正式な評価区間を以下として解析している。

- 2026-07-22 13:05 JST ～ 2026-08-02 19:15 JST
- 対象: raspberrypi2 / location-b
- 通常観測周期: 約5分

5分周期に正規化した評価結果:

| 指標 | 結果 |
|---|---:|
| 期待観測枠 | 3,243 |
| 対応観測枠 | 3,240 |
| 欠測枠 | 3 |
| 取得率 | **99.91%** |
| 欠測率 | **0.09%** |
| 期待時刻からの平均ずれ | **0.600秒** |

この区間では、少なくともIoT計測・クラウド記録系については高い継続性でデータ取得できていた。

ただし、養液温度は平均33.06℃で、30℃以上が87.8%を占めており、植物にとって常に良好な栽培環境であったとは評価していない。

## 3. 臨地実務期間中に発生した転倒・枯死

2026-07-20～2026-08-28のベトナム臨地実務期間中も、国内では植物IoT装置を継続運用していた。

2026-08-04に家族が現地確認した際、栽培装置が転倒し、植物が著しく萎凋・枯死した状態で発見された。また、電源コードが抜けた状態であった。

発生から発見まで時間差があるため、8月4日は事故発生日ではなく「発見日」として扱う。

一方、保存されていたログを解析すると、2026-08-02 19:15頃までは通常状態の観測が存在し、その直後の19:16:39に急激な状態変化が記録されていた。

主な変化:

- 水位: `water_ok` → `low_water`
- `float_switch_triggered = true`
- Vitality Score: 約79 → 5
- 照度の急変
- DS18B20: 85.0℃（実温度ではなくセンサ読取異常を示すエラー様値と解釈）

その後、Supabaseへの観測は約39時間途絶した。

以上から、8月2日19:16頃に装置・センサ系へ急激な異常が発生した可能性が高いと考えている。ただし、現時点では「この時刻に転倒した」「特定の原因によって転倒した」とまでは断定せず、観測事実と推論を分離して扱う。

この事故については、単なる失敗としてではなく、長期運用型植物IoTシステムにおける物理異常・給水異常・監視継続性の限界を検討するケースとして分析している。

## 4. 現時点で不足している評価

毛細管現象による給水方式そのものは実運用で使用していたが、毛細管給水自体の定量評価は十分に行えていない。

既存データから確認できるのは主として、

- 貯水部の水位状態
- 養液温度
- 照度
- Vitality Score
- システムのデータ取得状況

であり、以下は直接計測できていない。

- 毛細管現象による単位時間当たりの給水量
- フェルト等の給水材による輸送性能
- 水位差・距離等による給水性能の変化
- 貯水部から植物側まで実際に給水が成立しているか
- 給水経路の異常をIoTデータからどこまで検知できるか

特に、既存のフロートスイッチが `water_ok` であっても、「植物へ十分な水が届いている」ことまでは保証できないという課題がある。

## 5. 10月6日までに追加検討したい実験

### A. 毛細管給水の基礎特性評価

候補:

- 給水材（フェルト等）の条件を固定
- 水位差・高さ・距離等を変化
- 一定時間ごとの水移動量を重量または体積で測定
- 条件ごとの給水速度・安定性を比較

### B. 実植物を用いた短期連続運用

基礎実験で条件を決めた後、実際の鉢・植物へ接続して数日程度連続運用する。

観測候補:

- 貯水量 / 水位
- 養液温度
- 照度
- 周辺温湿度
- Vitality Score
- 植物状態の写真記録
- 必要に応じて給水量・重量変化

### C. 異常状態の評価

安全に再現可能な範囲で、例えば以下を比較する。

- 正常給水
- 給水材の接触不良
- 貯水不足
- 給水経路の断絶

その際、既存IoTセンサでどの程度異常を捉えられるか、追加センサが必要かを検討する。

## 8. 現時点の位置づけ

現状は、IoTシステムの実装と長期運用データは存在し、事故前のシステム稼働性能について定量評価も進んでいる。

一方、研究の中心に据えたい毛細管給水については定量評価が不足している。

したがって今後は、システム機能をさらに追加することよりも、**毛細管現象による受動給水を定量評価し、その状態をIoTでどこまで観測・異常検知できるかを実験によって明らかにすること**を優先する。
