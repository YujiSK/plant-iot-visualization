# 卒業研究 進捗・打ち合わせ用サマリ

更新日: 2026-09-08

## 1. 研究のこれまでの流れと現在の方向

本研究では当初から、毛細管現象を利用した受動給水方式を植物管理システムに取り入れることを検討してきた。

実際の栽培装置にもフェルト等を用いた毛細管給水方式を採用し、初期段階では給水材の吸水・給水性能について簡易的な測定も行った。

一方、その後は以下のようなIoT監視システムの構築・長期運用に研究の比重が移った。

- 各種センサによる環境・水位状態の取得
- センサデータのクラウド蓄積
- Web等での可視化
- Vitality Scoreによる状態指標化
- 通知機能の実装
- 長期連続運用

その結果、毛細管給水方式自体は継続して使用していたものの、毛細管現象による給水性能の定量評価は十分に深掘りできていない。

そのため今後は、新たに研究テーマを変更するのではなく、**当初から扱ってきた毛細管現象による受動給水について定量評価を補完し、これまで構築してきたIoTセンシングと組み合わせて評価する**方向で研究を整理している。

現時点の研究上の問いは、概ね以下を想定している。

> 毛細管現象を利用した受動給水は、小規模な植物管理においてどの程度安定して機能するか。また、その給水状態や異常をIoTセンシングによってどこまで観測・検知できるか。

今回の打ち合わせでは、この研究目的・評価方法が卒業研究として妥当かを確認したい。

---

## 2. これまでに構築・実施した内容

### システム

Raspberry Piを中心として植物IoTシステムを構築し、実植物を用いた継続運用を行った。

主な構成・機能:

- DS18B20による養液温度計測
- BH1750による照度計測
- フロートスイッチによる水位状態取得
- Vitality Scoreによる状態指標算出
- FastAPI等によるデータ処理
- Supabaseへのセンサログ蓄積
- GitHub Pages等による可視化
- LINE / Slack等への通知機能

栽培時の給水には、当初から検討していたフェルト等による毛細管現象を利用した受動給水方式を使用していた。

また、初期段階ではフェルトの吸水・給水挙動について簡易的な測定を行ったが、比較条件・反復数・評価指標を十分に揃えた本評価には至っていない。

### 長期運用データ

事故前の正式な評価区間を以下として解析している。

- 2026-07-22 13:05 JST ～ 2026-08-02 19:15 JST
- 対象: raspberrypi2 / location-b
- 通常観測周期: 約5分

5分周期に正規化した評価結果:

| 指標 | 結果 |
|---|---:|
| 期待観測枠 | 3,243 |
| 対応観測枠 | 3,240 |
| 欠測枠 | 3 |
| 取得率 | **99.91%** |
| 欠測率 | **0.09%** |
| 期待時刻からの平均ずれ | **0.600秒** |

この区間では、少なくともIoT計測・クラウド記録系については高い継続性でデータ取得できていた。

ただし、養液温度は平均33.06℃で、30℃以上が87.8%を占めており、植物にとって常に良好な栽培環境であったとは評価していない。

## 3. 臨地実務期間中に発生した転倒・枯死

2026-07-20～2026-08-28のベトナム臨地実務期間中も、国内では植物IoT装置を継続運用していた。

2026-08-04に家族が現地確認した際、栽培装置が転倒し、植物が著しく萎凋・枯死した状態で発見された。また、電源コードが抜けた状態であった。

発生から発見まで時間差があるため、8月4日は事故発生日ではなく「発見日」として扱う。

一方、保存されていたログを解析すると、2026-08-02 19:15頃までは通常状態の観測が存在し、その直後の19:16:39に急激な状態変化が記録されていた。

主な変化:

- 水位: `water_ok` → `low_water`
- `float_switch_triggered = true`
- Vitality Score: 約79 → 5
- 照度の急変
- DS18B20: 85.0℃（実温度ではなくセンサ読取異常を示すエラー様値と解釈）

その後、Supabaseへの観測は約39時間途絶した。

以上から、8月2日19:16頃に装置・センサ系へ急激な異常が発生した可能性が高いと考えている。ただし、現時点では「この時刻に転倒した」「特定の原因によって転倒した」とまでは断定せず、観測事実と推論を分離して扱う。

この事故については、単なる失敗としてではなく、長期運用型植物IoTシステムにおける物理異常・給水異常・監視継続性の限界を検討するケースとして分析している。

## 4. 現時点で不足している評価

毛細管現象による給水方式は研究初期から検討・採用しており、簡易的な給水実験も一部実施している。

一方、IoT監視システムの構築・長期運用に重点を置いた結果、毛細管給水そのものについては、卒業研究の本評価として十分な定量データを取得できていない。

既存の長期運用データから確認できるのは主として、

- 貯水部の水位状態
- 養液温度
- 照度
- Vitality Score
- システムのデータ取得状況

であり、以下は十分に評価できていない。

- 毛細管現象による単位時間当たりの給水量
- フェルト等の給水材による輸送性能
- 水位差・距離等による給水性能の変化
- 給水性能の時間的な安定性
- 貯水部から植物側まで実際に給水が成立しているか
- 給水経路の異常をIoTデータからどこまで検知できるか

特に、既存のフロートスイッチが `water_ok` であっても、「植物へ十分な水が届いている」ことまでは保証できないという監視上の課題がある。

したがって、これまでの簡易実験を予備実験として位置づけ直し、条件・反復・評価指標を整理した追加評価を行う必要がある。

## 5. 10月6日までに優先する追加評価

10月6日時点で全ての実験を完成させることよりも、**研究質問と評価方法を確定し、予備的であっても一度「実験 → 解析 → 考察」までの研究サイクルを通すこと**を優先する。

### A. 毛細管給水の基礎特性評価

まず条件を絞り、毛細管給水そのものを定量化する。

候補:

- 給水材（フェルト等）の条件を固定
- 水位差・高さ・距離等のうち主要な1～2条件を比較
- 一定時間ごとの水移動量を重量または体積で測定
- 給水速度および時間的安定性を評価

最初から多数の材質・条件を比較するのではなく、卒論の主張に必要な最小条件で開始する。

### B. 実植物を用いた短期連続運用

基礎実験で条件を決めた後、実際の鉢・植物へ接続し、数日程度の連続運用を行う。

観測候補:

- 貯水量 / 水位
- 養液温度
- 照度
- 周辺温湿度
- Vitality Score
- 植物状態の写真記録
- 必要に応じて重量変化等による給水状態の補助計測

### C. 正常・異常状態の予備比較

10月6日までには、まず安全に再現可能な少数条件で正常・異常を比較する。

例:

- 正常給水
- 給水材の接触不良または給水経路の断絶
- 必要に応じて貯水不足

この段階では、既存IoTセンサでどの程度変化を捉えられるかを確認し、本評価で必要となる追加センサ・評価指標を判断する。

6. 10月6日の研究室内発表までに最低限到達すべき実験・解析水準

## 8. 現時点の位置づけ

現状は、毛細管現象による受動給水の着想・簡易実験から始まり、実際の栽培装置への導入、IoT監視システムの構築、長期運用まで進んでいる。

一方、その過程でIoT側の実装・運用に重点が移り、毛細管給水そのものの定量評価が十分に深掘りされなかった。

したがって今後は、研究テーマを新たに変更するのではなく、**当初の研究構想に立ち戻り、これまで不足していた毛細管給水の定量評価を補完した上で、既存のIoTセンシングと統合して評価する**。

10月6日までに研究を完全に終了させることを前提とせず、まず基礎評価から実植物での予備比較まで一度研究サイクルを成立させる。その結果と指導教員からの指摘を踏まえ、10月末までに反復数・評価期間・比較条件を増やし、本評価を完成させる方針とする。
