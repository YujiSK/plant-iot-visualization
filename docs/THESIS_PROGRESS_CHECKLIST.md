# 卒業研究 進捗評価チェックリスト

本チェックリストは、卒業研究を
「問題設定 → 提案・研究構成 → 実装 → 実験設計 → 評価 → 考察」
の観点から自己点検するためのものです。

> 注意: 本チェックリストは卒業研究の公式採点基準ではなく、研究進捗を整理するための内部管理用チェックリストです。

## 1. 問題設定
- [ ] 研究対象となる問題を一文で説明できる
- [ ] なぜその問題を扱う必要があるか説明できる
- [ ] 中心的な研究質問が明確になっている
- [ ] IoTセンシングに関する研究質問が明確になっている

## 2. 提案・研究構成
- [ ] 毛細管給水とIoTセンシングの役割を区別できている
- [ ] 研究質問と実験内容が対応している
- [ ] 卒論として扱う範囲を限定できている
- [ ] 毛細管給水の定量評価とIoT観測の関係を説明できる

## 3. 実装
- [x] センサデータ取得
- [x] APIによるデータ送信
- [x] Supabaseへの保存
- [x] Web可視化
- [x] 連続ログの取得実績がある
- [ ] 必要に応じた実験用計測環境の追加

## 4. 実験設計
- [ ] 独立変数を決定
- [ ] 条件数を決定
- [ ] 反復数を決定
- [ ] 1回あたりの測定時間を決定
- [ ] 給水量の測定方法を決定
- [ ] 毛細管材・長さ・幅など固定条件を決定
- [ ] 蒸発等の影響を考慮した対照条件を設定
- [ ] 「安定性」の評価指標を決定

## 5. 評価
- [ ] 単位時間あたり給水量を算出
- [ ] 累積給水量を算出
- [ ] 条件間比較を実施
- [ ] 反復間のばらつきを評価
- [ ] 給水停止・不安定化の有無を確認
- [ ] 既存IoTログとの対応を確認
- [ ] IoTで把握できる状態と把握できない状態を整理

## 6. 考察
- [ ] 中心的な研究質問に結果から回答できる
- [ ] IoTセンシングに関する研究質問に回答できる
- [ ] 毛細管給水方式の適用条件・限界を整理
- [ ] センサ構成の限界を整理
- [ ] 今後の改善点を整理

## 現時点での優先順位

1. 先生との打ち合わせで研究構成を確認する
2. 毛細管給水実験の独立変数を1つに絞る
3. 固定条件・条件数・反復数・測定時間を決める
4. 基礎実験を開始し、最初の定量データを得る
5. 結果をもとにIoTログとの対応可能性を評価する

## 現在の研究質問案

### 中心的な研究質問

毛細管現象を利用した受動給水において、給水条件の違いが給水量と安定性にどのような影響を与えるか。

### IoTセンシングに関する研究質問

既存のIoTセンシングによって、毛細管給水状態や異常をどの程度把握できるか。
