## 4. QUANTITATIVE_RESULTS

### 集計定義

通常周期は実装の300秒とローカル設定を根拠にする。ただし過去の全時点の環境変数変更履歴までは残存していない。全期間指標は**同じ300秒設定を基準とした名目測定枠の評価**であり、稼働予定時間が確定したSLA指標ではない。

- 生行件数：`COUNT(*)`。追加測定・再送重複・試験を混ぜたままの値。
- 最近傍5分枠：UNIX秒 `t` を `300*floor((t+150)/300)` へ割り当てる。1枠複数行は1枠として数える。許容窓は `[-150,+150)` 秒。
- 期待件数：半開区間 `[A,B)` なら `(B-A)/300`。端点を含む期待時刻列なら `floor((B-A)/300)+1`。
- 枠充足率＝記録の存在する期待枠数÷期待枠数×100。欠測枠率＝100−枠充足率。
- センサー値欠損率＝NULL行数÷対象行数×100。値が非NULLであることと妥当な物理測定であることは区別。
- 観測間隔／最長内部空白：device・sourceごとに `LAG(created_at)`。最後の記録から監査日までの末尾空白は内部空白に含めない。

単純な5分区間への切り捨てでは18:59:59と19:00:02のような揺れが枠を分割するため、取得率には最近傍法を採用した。比較用の切り捨て集計もQ:coverageに残す。`daily_quality.csv` のnearest_slotsは生行の日付でGROUP BYした診断値で、日境界を跨ぐため日別取得率には使用しない。
